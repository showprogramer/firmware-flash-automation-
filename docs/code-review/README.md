# 代码审查目录

## 使用约定

| 位置 | 放什么 |
|------|--------|
| **本目录（根）** | **仅当前仍有效、会继续更新**的审查（活文档） |
| **`archive/`** | 已闭环的历史审查；只读备查，不再当任务看板 |

新审查仍按 `AGENTS.md` 命名：`REVIEW-YYYYMMDD-short-name.md`，写在本目录；**议题全部关闭并合入后**，移入 `archive/`，并在 `archive/INDEX.md` 补一行。
