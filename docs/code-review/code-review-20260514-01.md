### 问题 1：手控固件在混合型号父目录下归属错误

**类型**： Bug修复

**模块**： `src/fwasset/core/file_scan.py`, `tests/test_file_scan.py`

**问题描述**
- 手控固件目录位于包含多个型号的父目录下时，扫描结果把型号目录固定识别为根目录下第一级目录。
- 当父目录名称包含多个型号或历史命名信息时，树形结构可能显示到不相干的型号目录下，程序目录和版本信息也会随之异常。

**处理方案**
- 扫描时先解析资产型号，再按型号 token 在相对路径各级目录中寻找匹配目录。
- 对 `handcontrol_ui` 类型选择最接近文件所在位置的型号目录，使 `L26A手控...` 和 `L50S手控...` 这类目录分别作为自身型号目录。
- 其他固件类型保留原有优先使用上层型号目录的行为，避免影响主板、屏幕等既有分组。
- 增加混合父目录回归测试，覆盖 `L26AmaxL50S` 下两个手控目录分别识别的场景。

**状态**： ⏳ 验证中

**类型**： Bug修复

**模块**： `src/fwasset/core/file_scan.py`, `tests/test_file_scan.py`
