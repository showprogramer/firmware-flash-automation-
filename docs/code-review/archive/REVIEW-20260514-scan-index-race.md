### 问题 2：扫描中点击按钮会误开目录选择器

**类型**： 用户体验

**模块**： `src/fwasset/ui/firmware_list_panel.py`

**问题描述**
- 扫描按钮原来固定绑定 `_choose_root_and_scan()`，扫描中点击仍会弹出目录选择器。

### 问题 3：取消事件闭包读取可变属性存在竞态

**类型**： Bug修复

**模块**： `src/fwasset/ui/firmware_list_panel.py`

**问题描述**
- 后台 `_work()` 曾从 `self._scan_cancel_event` 读取取消事件。
- 若 UI 状态在后台执行前变化，后台任务可能拿到 `None` 或错误事件。

**处理方案**
- 创建局部 `cancel_event`，赋给面板状态后由后台闭包固定引用该局部对象。
- 取消时只 set 事件，不提前清空；任务完成后仅清理当前扫描对应的事件。
- 增加竞态回归测试，确认后台任务收到的是原始事件对象。
