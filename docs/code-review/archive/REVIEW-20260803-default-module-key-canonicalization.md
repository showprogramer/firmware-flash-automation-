## Issue 1：目录短键与 catalog 规范键可同时成为默认

实际配置同时存在 `快捷键 = "量产_默认"` 与 `快捷键程序 = "贝乐"`。两键代表同一模块，但旧归一规则没有将它们关联，因此两个变体都显示默认，方案补齐和自动更新也可能按顺序采用旧值。

**要求：** 历史短键读取时兼容但优先规范键；下次设置默认时删除短键，只保留 `快捷键程序`。

**处置：** ✅ 已完成。`canonical_module_dir()` 将“快捷键 / 快捷按键 / 快捷键-旋钮”归一为“快捷键程序”；读取默认徽章和方案补齐时规范键优先；默认写入会移除全部同义旧键；自动更新共享来源同样优先规范键。

## 验收记录

- 自动化：默认配置服务、默认徽章 / 方案补齐与自动更新共享来源共 24 passed。
- Windows 人工验证（2026-08-03）：用户确认重复键只显示一个默认，重新设置默认后 TOML 合并正确，且右键菜单操作正常。
- 结论：全部议题关闭，人工验证通过，归档备查。
