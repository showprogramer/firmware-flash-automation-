# 烧录工具快速配置指南

## 目标
让固件刷机工具实现"一键打开"，无需每次手动寻找工具路径。

## 推荐方式：自动发现

### 1. 准备工具文件夹
在 `fwasset.exe` 同目录创建 `tools` 文件夹，将各类烧录工具放入：

```
fwasset.exe
├── tools/
│   ├── 主板烧录工具/
│   │   └── ISP.exe
│   ├── 语音烧录工具/
│   │   └── VoiceFlash.exe
│   ├── 3D机芯烧录工具/
│   │   └── 3D_Flash.exe
│   └── ...
├── firmware_catalog.toml
└── config.toml
```

### 2. 自动发现
启动程序后：
1. 点击侧边栏的 **"工具中心"** 按钮
2. 点击 **"自动发现工具"**
3. 程序会自动扫描 `tools` 文件夹，识别各类烧录工具
4. 配置自动保存，下次启动无需重复操作

## 备选方式：手动配置

如果工具分散在不同位置：
1. 在固件列表中选择需要刷机的固件类型
2. 在右侧"操作区"点击 **"浏览..."**
3. 选择对应的烧录工具可执行文件
4. 配置自动保存

## 日常使用

### 场景：刷写主板程序
1. 在左侧搜索框输入型号（如 L50S）
2. 选择对应的主板程序条目
3. 点击 **"打开烧录工具"** - 工具自动启动
4. 在烧录工具中加载固件文件进行刷写

### 场景：手控UI一键刷机
1. 搜索手控型号和版本
2. 插入U盘
3. 点击 **"一键智能刷机"**
4. 程序自动完成：清理→复制→弹出

## 工具中心功能

点击侧边栏 **"工具中心"** 可：
- 查看所有烧录工具的配置状态
- 批量自动发现未配置的工具
- 手动修改任意工具的路径
- 一键启动任意工具
- 快速打开 `tools` 文件夹

## 注意事项

1. 工具路径保存在 `firmware_catalog.toml` 中，可以手动编辑
2. 使用相对路径时，以程序所在目录为基准
3. 支持 `.exe`、`.bat`、`.cmd` 格式的可执行文件
