## 一、目标

L36 目录整理的核心目标：
1. **结构极简**：扁平化目录，去除无意义的嵌套，人工能快速判断通用、方案定制、单模块定制。
2. **数据驱动查询**：应用使用 4 个结构化字段（category, platform, scheme_name, scheme_path）和 `方案配置.toml` 实现多条件过滤，而不是依赖人工逐层点开目录。
3. **消除冗余与空占位**：定制方案不再保留空占位目录，而是通过 TOML 自动回源引用通用模块。
4. **统一应用内管理**：未来的增删改查均在软件内通过 UI 操作，底层自动映射到标准目录和 TOML。

## 二、最终确定的目录结构标准

### 2.1 根结构与通用区
型号由根目录表达（如 `L36程序/`），一级目录只保留 `通用/` 和 `定制/`。
取消“标准单机芯3D”等平台中间层，直接将模块平铺在通用区下，保持扁平。

```text
L36程序/
├── 通用/
│   ├── 主板程序/
│   │   ├── 量产/
│   │   └── 减少灯光亮度/
│   ├── 手控UI/
│   │   ├── 量产中性/
│   │   └── 无健康检测/
│   ├── 蓝牙程序/
│   │   ├── 中文-通用/
│   │   ├── 英文-通用/
│   │   └── 英文-增加2参数/
│   ├── 语音程序/
│   │   ├── 中文-通用/
│   │   └── 英文-通用/
│   ├── 快捷键/
│   │   ├── 量产/
│   │   └── 贝乐/
│   ├── 3D机芯版程序/
│   ├── 2D机芯版程序/          ← (单机芯2D唯一的区别所在，无程序时可为空)
│   ├── 腿部程序/
│   ├── 双机芯-上3D-下2D/      ← (独立主板存放处)
│   └── 接线图/
```

### 2.2 定制区（仅整机方案）
定制区直接以 `方案名` 作为二级目录，仅保留整机定制方案。单模块变体已归入通用区。

```text
├── 定制/
│   ├── 以色列-Royal-Z9/
│   │   ├── 方案配置.toml
│   │   ├── 主板程序/
│   │   ├── 手控UI/
│   │   ├── 蓝牙程序/
│   │   └── 语音程序/
│   ├── 葡萄牙-凡强/
│   ├── 西班牙/
│   ├── 越南-娉娉-24模式/
│   ├── 越南-娉娉-12模式/
│   └── 马来西亚-ROYAI/
```

> **设计原则**：定制区只放整机方案。单模块变体（如"防夹功能"主板、"俄语"手控UI）归入通用区，搜索时按关键字即可命中（如 "L36 主板 防夹功能"）。

## 三、方案配置文件 (TOML)

每个定制方案目录下自动生成一个 `方案配置.toml`，用于描述方案元数据。对于缺失的模块，软件会自动回源到通用区（不需要显式写在文件中，软件根据平台默认逻辑自动补齐）。

```toml
# 定制/以色列-Royal-Z9/方案配置.toml
name = "以色列-Royal-Z9"
platform = "标准单机芯3D"
```

## 四、代码改造计划 (Phase 5)

目录整理完成后，需要同步改造 SQLite 数据库和扫描器。

### 4.1 核心数据结构扩展
`FirmwareAsset` 仅新增 4 个核心字段，保持数据库精简，其余如 region/customer 留在 TOML 中，供 UI 层面的全文检索使用：
```python
category: Literal["common", "custom"]
platform: str        # "标准单机芯3D" / "单机芯2D" / "双机芯-上3D-下2D"
scheme_name: str     # 例如 "以色列-Royal-Z9"
scheme_path: str     # 定制方案根目录
```

### 4.2 SQLite Schema 变更 (v2 -> v3)
```sql
ALTER TABLE assets ADD COLUMN category TEXT DEFAULT '';
ALTER TABLE assets ADD COLUMN platform TEXT DEFAULT '';
ALTER TABLE assets ADD COLUMN scheme_name TEXT DEFAULT '';
ALTER TABLE assets ADD COLUMN scheme_path TEXT DEFAULT '';

CREATE INDEX idx_assets_category ON assets(category);
CREATE INDEX idx_assets_platform ON assets(platform);
CREATE INDEX idx_assets_scheme ON assets(scheme_path);
```

### 4.3 UI 层级优化
1. **工作台概念**：软件将由静态读取变为具有包管理能力的“工作台”。增删改查均在软件内操作。
2. **烧录模式隔离**：手控 UI 支持 U 盘一键导出 (`auto_usb`)，其他模块联动官方烧录工具 (`tool_launch`)。
