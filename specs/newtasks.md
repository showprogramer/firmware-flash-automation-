```
管理员视角：config.toml 配置 tool_root = "D:\...\摩众—按摩椅刷程序工具"（只配一次）
```

- [x] `config.toml` 新增 `[paths] tool_root` 配置项，指向已有的刷程序工具库根目录
- [x] `settings.py` 读取 `TOOL_ROOT`，默认值为空字符串（空时走默认发现逻辑）
- [x] `firmware_catalog.toml` 每个 `tool_launch` 类型新增 `tool_dir` 字段（约定子目录名，如 `tool_dir = "刷主板程序工具"`）
- [x] `tool_discovery.py` 搜索优先级调整为：

- [x] 创建 `tools/` 目录骨架模板（用于 exe 分发的兜底方案）：
