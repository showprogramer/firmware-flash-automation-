## 当前规则

后续改原型或做正式 CRUD 时以本节为准。展示层用大白话；内部标识（`platform`、`shared_modules`、`平台配置.toml`）不改名。

### 范围

- 只管理当前程序文件夹根内的型号（单工作区）。根外型号不处理。
- 打开页面时型号、方案、程序、借用均为空；「软件修复」也不带回演示数据。
- 不接入 `src/fwasset/`，不写真实目录 / TOML / SQLite。

### 枚举

- **机芯类型**（内部字段仍叫 `platform`）：`单3D`、`单2D`、`双2D`、`上3D下2D`。仅新建型号单选；定制方案继承型号，界面写「机芯类型：随型号确定」。
- **程序类型** `TYPES`：`主板程序`、`手控UI`、`蓝牙程序`、`语音程序`、`快捷键程序`、`腿部程序`、`机芯板程序`、`旋钮开关`、`音波板`、`其他资料`。
- **归属厂商** `VENDORS`：预置 `摩众`、`国瑞`、`亿微`、`明锐`，默认第一项。不知道就先填一个，之后用更新程序改，不必换文件。名单在**设置**里添加，不写死在代码里。详情区展示，主表不占列；借用沿用来源，不另选。

### 型号与方案

- 型号是独立单元：独立目录、`型号配置.toml`、机芯类型。一切在软件内完成，不靠资源管理器建目录。
- 无型号时：主表提示先「＋ 新建型号」；「新增程序」禁用。建完自动切到该型号；删空后回到无型号。
- 型号下拉可搜索；右键重命名 / 删除型号。
- 定制方案：导航「＋ 新建定制方案」或新增程序时顺带新建；右键重命名 / 删除。空方案仍显示，由人删除。删方案 = 其下程序进回收站，可撤销。被删程序上的借用变「用不了」，撤销后恢复。

### 程序

- 主表 4 列：程序名称 / 通用·定制 / 版本 / 程序文件。仅「全部类型」下插类型分隔行。`↑`/`↓` 跳过分隔行。
- 新增第一步二选一（无说明文字）：`添加文件` / `选择别的型号已有程序`。
- 添加文件：单一拖放区 +「选择…」。程序文件、文件夹、压缩包都可以直接放入，不弹二选一。也可拖进主窗口任意位置打开新增并预填。路径只预填通用/定制方案与程序名称，不推断类型。类型、厂商自选。手控 UI 只提示需要 `.rom` + `.pkg`，不阻断保存。版本从 `.rom` 文件名解析。介绍文件随程序一起保存，界面不展示，打开文件夹能看到。
  Qt 落地：拖入三种都能收。「选择…」打开多文件对话框（含压缩包）；系统对话框通常不能同时选文件夹，文件夹靠拖入，不要再做选项菜单。
- 重命名：详情铅笔或 `F2`，只改程序目录名。删除：右键、`Del`、详情底部弱化链接；反查「谁在用」后二次确认，有借用时必须勾选；语义为回收站，提示条可撤销。
- 设为默认：详情区，无模态。定制方案缺某类型时用本型号该类型默认程序补齐；给方案加专属程序，不要去改通用程序。删掉专属后自然回到默认。
- 更新：详情「更新程序」。可改文件夹、类型、厂商、名称、范围。只改厂商等资料时不必放入新程序，也不问旧程序怎么处理；放入新程序后才出现「原来的程序怎么办」（放进回收站 / 保留为备用副本，不预选）。副本在当前程序文件夹的 `旧版本/` 下，不进主表。改类型且原是默认时，必须提示原类型默认失效。
- 手控 UI：详情可「复制手控文件到 U 盘」，只复制配对 `.rom` / `.pkg`。

### 借用（型号 → 型号，按程序类型一条）

- 登记写在借入方。一个型号一个类型只能一条；再记要确认覆盖。
- 两种模式：`固定用这个程序` / `跟随这个程序`（来源更新、改名、换文件夹后借入方自动同步）。不要做成「跟着对方的默认走」。
- 主表合成一行（`来自 X` / `跟随 X`），只读。来源失效显示「用不了」。已登记类型的本型号同类程序置灰（B4b，不得回源到本地副本）。
- 「不再用别的型号的程序」只删登记，不删任何文件。
- 正式 core 落地需把 `SharedModuleRef` 从 `follow_default` 迁到跟随指定程序的稳定标识。本原型不改 `src/fwasset/`。

### 设置

- 顶栏 `⚙ 设置`：程序文件夹、归属厂商名单（可添加）、整行按钮「软件修复」。新厂商几年才可能有一家，不放主界面；程序员不在时也能在软件内加。
- 维护是过渡期能力，不放主界面。Qt 落地同样归设置页。

### 交互通则

- 写操作立即生效。**只有删除类操作带提示条撤销**（删除程序 / 型号 / 方案 / 备用副本、解除借用）；新增、重命名、更新、设为默认、登记借用、恢复副本一律不带撤销，靠反向操作纠正（详见 `TASK-20260903-crud-write-semantics.md` D10）。模态只用于：删除/删方案、新增、更新、复制到 U 盘、软件修复进度、新建型号/方案。
- 界面禁止出现：TOML、引用、配置键、共享/共用、维护与修复、开始维护、展示层的「平台」。

## 非目标

- 不接入正式 CRUD service。真实落盘、删除时的 TOML 级联另立 TASK。
- 不做复制/移动程序、通用版本折叠、目录版本命名、版本手工覆写、右键复制路径。
- 不支持方案级借用、多根、切根。

## 正式 CRUD 另立 TASK 时不要丢

- 扫描器必须排除程序文件夹内的 `旧版本/`。
- 多个 `[[platform]]` 块并存时，默认值写哪一块尚未定。
- 更新改类型后，旧类型默认与借用关系的迁移规则未定，界面必须先展示影响。
- 跟随借用需持久化来源程序稳定标识。

## 验收标准

- 浏览器直接打开 HTML，无安装、构建或网络依赖。
- 初始为空；无型号时先建型号（机芯类型四选一）；筛选（范围 / 10 类 chip / 搜索）联动；主表 4 列。
- 新增二选一；添加文件可拖放程序文件 / 文件夹 / 压缩包（无二选一菜单）；类型与厂商自选；可顺带新建方案。
- 借用按类型 + 来源型号 + 具体程序 + 固定/跟随；失效与 B4b 可见。
- 更新可改厂商且不必换文件；备用副本不进主表，可交换恢复。
- 设置含程序文件夹、可添加的归属厂商名单、软件修复。删除类操作可撤销，其余写操作不带撤销。无旧术语。
