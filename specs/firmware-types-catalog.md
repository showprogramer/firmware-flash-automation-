## 六、每台按摩椅需烧录的板卡数量估算

| 机型配置 | 需烧录板卡 | 数量 |
|---------|-----------|------|
| 基础家用款（单2D机芯） | 主板 + 手控 + 蓝牙 + 语音 + 快捷键 | **5 个** |
| 家用双机芯款（3D+2D） | 上述5个 + 3D机芯板 + 2D机芯板 | **7 个** |
| 商用款 | 家用基础上 + 商用主板 + 占座 + 刷卡 | **可多达10个** |
| 带腿机/膝盖机 | 上述 + 1~3 个 | **可多达13个** |

---

## 七、关键结论

1. 公司至少有 **19 种不同板卡**的固件类型需要管理
2. 每台机器出货前需烧录 **5~13 个不同板卡**
3. 不是"一个型号一个固件"，而是 **一个型号对应一组固件集合**
4. 部分固件跨型号通用（如蓝牙板在 L36/L39/L50 系列间共用），需记录兼容性
